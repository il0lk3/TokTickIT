| **Generating Peer Review Logs** | "หลักฐานการ Peer Review ของไฟล์ docs/lab-01/reviewer.md น่าจะต้องมีข้อมูลตามนี้นะ"<br><br>**My Reflection:** การทำเอกสารมักใช้เวลามาก การป้อนข้อมูลดิบให้ AI ช่วยจัดโครงสร้างให้อ่านง่าย ทำให้งานเป็นระเบียบและรวดเร็วขึ้น สิ่งที่ได้เรียนรู้คือ AI เป็นผู้ช่วยลดภาระงานซ้ำซากได้ดีเยี่ยม แต่เรายังต้องเป็นคนตรวจทานความถูกต้องในท้ายที่สุดเสมอ |
| **Improving API Tests (Issue 4)** | "รีวิวจากเพื่อน - ... เพิ่ม test กรณีที่ API error แล้วก็เช็ก response ว่ามี id กับ name ครบไหม"<br><br>**My Reflection:** การใช้ AI ช่วยแก้โค้ดจาก Feedback นี้ทำให้ได้เรียนรู้วิธีการเขียน Test ในระดับที่ลึกขึ้น (เช่น เช็คระดับ Property) และเห็นว่า Test ที่ดีไม่ใช่แค่เช็คว่าทำงานสำเร็จ (Success) แต่ต้องเช็คครอบคลุมถึงกรณีที่พัง (Error 404) ด้วย |
